# Утренний дашборд продаж

Каждое утро (~06:00 МСК) собирает заказы за вчера с Озона, Wildberries и Яндекс.Маркета
и пишет в Google Таблицу. Подробности — в `CLAUDE.md`.

Репозиторий открытый: ключей и данных здесь нет и быть не должно (все ключи — в GitHub Secrets).

## Структура
- `main.py` — точка входа
- `dashboard/collectors/` — сборщики по площадкам (пока заглушки)
- `dashboard/sheets.py` — запись в Google Таблицу
- `.github/workflows/daily.yml` — ежедневный запуск
- `.github/workflows/keepalive.yml` — раз в месяц не даёт GitHub отключить расписание
